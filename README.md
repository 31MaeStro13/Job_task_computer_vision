## Как запустить локально

Скрипт полностью автономен, работает на **CPU** и не требует внешних библиотек (использует исключительно стандартную библиотеку Python 3.8+).

### 1. Генерация ответов на тестовых данных:
```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

### 2. Запуск и валидация на обучающих данных:
```bash
python postprocess.py data/train_predictions.jsonl answers_train.jsonl
python evaluate.py answers_train.jsonl data/train_labels.jsonl
```
